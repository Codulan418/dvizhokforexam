------------АЛГОРИТМ НАСТРОЙКИ И ИСПОЛЬЗОВАНИЯ------------
1. Из папки config выбрать тип подключения (mysqli.php или PDO.php), подключить БД в index.php в корневом в каталоге
2. В views/layout/main.php прописать header, footer для вашего сайта , в head прописать подключение к стилям и общий js-файл для всех страниц
3. В views/ прописать представление для статичных html страниц и страниц с выводом данных из БД.
4. Создать по шаблону файлы логики controllers и вывести данные нужные для вывода на странице-отображение в рендер
<!-- вот это рендер в шаблоне
$this->render('home', [
    'title' => 'Главная',
    // для добавление js-файла ОБЯЗАТЕЛЬНО пишите ', ' (запятую с пробелом)
    'js' => 'slider.js, script.js',
    'about' => $about,
]); -->
5. Прописать явный путь для нестандартных путей и главной страницы в config/route.php по шаблону:
['/about', 'AboutController@about', POST] 1 - путь без расширения, 2 - названиекласса@метод, 3 - метод для отправки данных, по умолчание стоит GET
